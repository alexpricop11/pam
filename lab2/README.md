# Laborator 2 — Learning App

Aplicație Flutter adaptivă inspirată din designul furnizat: Home și Courses, cu navigare, filtrare după căutare și filtre de cursuri.

## Rulare

```bash
flutter pub get
flutter run
```

Interfața limitează conținutul la 600 px pe tabletă și folosește layout proporțional pe telefoane mici, normale și late.
